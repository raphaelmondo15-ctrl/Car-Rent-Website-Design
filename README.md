# Car Rent Website Design

A modern, responsive Car Rental Web UI built using HTML and CSS.
This project showcases a clean layout with booking functionality, featured cars, and a fully responsive design.

## Features

Modern and clean UI design

Fully responsive layout

Hero promotional section

Car booking section

Car listing cards (Sport & SUV categories)

Scrollable car section on mobile

Responsive footer

Mobile-friendly navigation
